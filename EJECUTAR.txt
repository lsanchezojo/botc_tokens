1. Abre una terminal en la carpeta donde quieras instalar el proyecto.
2. Crea un entorno virtual (por ejemplo, en una carpeta llamada venv):
python -m venv venv
3. Activa el entorno virtual:
-> En Windows CMD:
venv\Scripts\activate
-> En PowerShell:
.\venv\Scripts\Activate.ps1
4. Instala el proyecto localmente dentro del entorno virtual:
pip install .
5. Ahora el comando botc_tokens estará disponible dentro del entorno virtual, en la ruta venv\Scripts\botc_tokens.exe.
De esta forma, todo queda contenido en la carpeta venv y puedes moverla o eliminarla cuando quieras, sin afectar el resto del sistema.
